# UbuntuServerHomelab
Documenting self-hosted Ubuntu server, built using Virtualbox on Windows.

## Initial_setup.md
Documents the initial setup and configuration of the server.

## LAMP stack setup.md
Setting up a LAMP (Linux, Apache, MySQL, PHP) stack to host a webpage displaying the contents of a database.

## User permissions.md
Creating additional user accounts, assigning users to groups, and configuring permissions and access.

## Server hardening.md
Hardening the server with a firewall, SSH access rules, key-based SSH authentication and automated security updates.
